    利用gh

    登陆：

    按提示选择：

    • 选 GitHub.com
    • 选 HTTPS
    • 选 Login with a web browser（会给你一个 8 位码）

    • 完成！gh 会自动帮你配置好 Git 认证

    之后 git push 直接用 HTTPS 就行，不会弹密码框。

    常见卡住的地方（提前帮你避开）

    问题 解决办法
    ERROR: Permission denied 说明 SSH 没配好，用 ssh -T git@github.com 测试，或改用 HTTPS 地址
    failed to push some refs 远程有 README 或文件（你创建时勾选了），先 git pull origin main --rebase 再 push
    想换分支名 git branch -m 旧名字 新名字
